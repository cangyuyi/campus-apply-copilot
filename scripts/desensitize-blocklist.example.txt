# 本地私密黑名单（示例文件，可提交）
#
# 用法：
#   1. 复制本文件为 scripts/desensitize-blocklist.local.txt
#   2. 在副本里填入你真实的项目名 / 公司名 / 部门名 / 投递系统名
#   3. 每次跑 check-desensitize.sh 都会逐词全文扫描，命中即失败
#
# 为什么用"本地文件"而不是写死在脚本里：
#   如果把真实公司名硬编码进 check-desensitize.sh，这个脚本本身就成了泄漏源
#   ——为了防泄漏反而把要保护的名字公开了。所以真实词条只存在本地副本里，
#   而 .gitignore 已忽略 *.local.txt。
#
# 写法：一行一个词，只写有辨识度的部分，不要写整句话。
#   支持 # 开头的注释行；空行会被忽略；匹配是固定字符串（非正则），
#   所以词条里的 . ( ) 等符号会按字面匹配。
#
# 示例（下面这些是占位符，请替换成你自己的）：
# XX科技
# XX事业部
# XX项目
# 某某网申系统
